Коммутативность: A∧B ≡ B∧A, A∨B ≡ B∨A Ассоциативность: (A∧B)∧C ≡ A∧(B∧C), (A∨B)∨C ≡ A∨(B∨C) Упрощения для ∧: X∧Л ≡ Л, X∧И ≡ X Упрощения для ∨: X∨Л ≡ X, X∨И ≡ И Упрощения для →: X→И ≡ И, Л→X ≡ И, X→Л ≡ ¬X, И→X ≡ X
#5 Тавтологии

Modus ponens и дистрибутивность

Modus ponens (правило отсечения):
A ∧ (A → B) → B
Дистрибутивность: A ∧ (B ∨ C) ≡ (A∧B) ∨ (A∧C) A ∨ (B ∧ C) ≡ (A∨B) ∧ (A∨C)
Доказательство дистрибутивности A∧(B∨C) ≡ (A∧B)∨(A∧C)

Разбираем два случая:

  1. A = Л: Левая часть = Л. Правая = Л∨Л = Л. ✓
  2. A = И: Левая = И∧(B∨C) = B∨C. Правая = (И∧B)∨(И∧C) = B∨C. ✓
Важнейшие тавтологии для доказательств
Транзитивность →: (A→B)∧(B→C) → (A→C) Контрапозиция: A→B ≡ ¬B→¬A Законы де Моргана: ¬(A∧B) ≡ ¬A∨¬B ¬(A∨B) ≡ ¬A∧¬B Отрицание →: ¬(A→B) ≡ A∧¬B Представление →: A→B ≡ ¬A∨B

#6 Определение

Равные множества. Подмножество. Пустое множество.

A = B ⟺ ∀x(x∈A ≡ x∈B) A ⊆ B ⟺ ∀x(x∈A → x∈B) ∅ — множество, не содержащее ни одного элемента; x∈∅ ложно для любого x
Единственность пустого множества: Если бы было два разных пустых множества ∅₁ и ∅₂, то в одном из них был бы элемент, которого нет в другом. Но в пустых нет ничего — различить их невозможно. Значит, пустое множество единственно.

Парадокс Рассела: Рассмотрим A = {x : x∉x}. Тогда A∈A ≡ A∉A — противоречие. Вывод: такого множества не существует; не всё является множеством.

#7 Определение

Операции над множествами

Объединение: x∈A∪B ≡ (x∈A)∨(x∈B) Пересечение: x∈A∩B ≡ (x∈A)∧(x∈B) Разность: x∈A\B ≡ (x∈A)∧¬(x∈B) Симм. разность: x∈A△B ≡ (x∈A)∧¬(x∈B) ∨ ¬(x∈A)∧(x∈B) Дополнение (до U): Ā = U\A
Связь с логикой: Теоретико-множественным тождествам отвечают логические тавтологии (и наоборот). Пример: (A∩B)\C = (A\C)∩B ↔ (A∧B)∧¬C ≡ (A∧¬C)∧B — тавтология (ассоциативность+коммутативность конъюнкции).

Характеристические функции операций: χA∩B = χA·χB, χĀ = 1−χA, χA\B = χA·(1−χB), χA∪B = 1−(1−χA)(1−χB)

#10–11 Определения

Конечное множество. Подсчёт. Правила суммы и произведения

Неформально: Множество конечно, если его элементы можно пересчитать. Результат подсчёта — мощность множества, |A|.

Декартово произведение A×B — множество всех упорядоченных пар (a,b), a∈A, b∈B.

Правило суммы: A∩B=∅ ⟹ |A∪B| = |A|+|B|

#12–13 Принципы

Принцип математической индукции

Принцип математической индукции:
Если A(0) истинно и ∀n(A(n)→A(n+1)) истинно, то A(n) истинно для любого n∈ℕ.

Запись: A(0) ∧ ∀n(A(n)→A(n+1)) → ∀n A(n)

Принцип полной математической индукции:
Если ∀n((∀k<n A(k)) → A(n)) истинно, то A(n) истинно для любого n∈ℕ.
(База вытекает автоматически: при n=0 посылка — квантор по пустому множеству — истинна.)
Доказательство правила произведения по индукции

По индукции по |A|.

База: |A|=1. A×B ↔ B через взаимно-однозначное соответствие (a₀,b)↔b. Значит |A×B| = |B| = 1·|B|.

Шаг: Выделим элемент a₀∈A, A₀=A\{a₀}. Тогда A×B = ({a₀}×B) ∪ (A₀×B) — непересекающееся объединение. По правилу суммы: |A×B| = |{a₀}×B| + |A₀×B| = |B| + |A₀|·|B| = (1+n)|B| = |A|·|B|. □

#14–15 Определение

Упорядоченная пара по Куратовскому. Бинарное отношение

Определение Куратовского: (x,y) := {{x},{x,y}}
Основное свойство: (x₁,y₁) = (x₂,y₂) ⟺ x₁=x₂ и y₁=y₂

Случай 1: x₁=y₁. Тогда (x₁,y₁)={{x₁}}. Следовательно, {{x₂},{x₂,y₂}} — одноэлементное множество, значит x₂=y₂. Из {{x₁}}={{x₂}} получаем x₁=x₂=y₁=y₂.

Случай 2: x₁≠y₁. {x₁,y₁} двухэлементное, должно равняться {x₂,y₂}. Одноэлементное {x₁}={x₂}. Отсюда x₁=x₂ и y₁=y₂. □

Бинарное отношение R на A,B — подмножество декартова произведения A×B. Запись: (x,y)∈R или xRy.

Бинарное отношение на A — подмножество A×A.

Функции. Инъекции, сюръекции, биекции. Композиция
▼
#16–17 Определение

Функция. Область определения. Область значений. Тотальная функция

Функция f: A→B — бинарное отношение f⊆A×B, для которого каждый a∈A встречается не более чем в одной паре (a,b)∈f.

Область определения: Dom(f) = {x∈A | ∃y∈B: (x,y)∈f}

Область значений: Range(f) = {y∈B | ∃x∈A: (x,y)∈f}

Тотальная (всюду определённая) функция: Dom(f) = A.
#18–20 Определения

Инъекция. Сюръекция. Биекция. Обратная функция

Инъекция: f — тотальная, f(x₁)=f(x₂) ⟹ x₁=x₂ (разные аргументы → разные значения).
Сюръекция: f — тотальная, Range(f)=B (каждое значение достигается).
Биекция: f — и инъекция, и сюръекция (взаимно однозначное соответствие).

Примеры инъекции: f:ℕ→ℕ, f(x)=x² — инъекция (из x₁²=x₂² следует x₁=x₂ для натуральных).

Примеры не инъекции: g:ℝ→ℝ, g(x)=x² — не инъекция (g(-1)=g(1)=1).

Обратная функция: Для биекции f:A→B определяется f⁻¹:B→A по правилу (x,y)∈f ⟺ (y,x)∈f⁻¹.

Теорема: Если f — биекция, то f⁻¹ — тоже биекция

Проверяем все свойства f⁻¹:

  • f⁻¹ — функция: из инъективности f. Если (y,x₁)∈f⁻¹ и (y,x₂)∈f⁻¹, то (x₁,y)∈f и (x₂,y)∈f → x₁=x₂ по инъективности f.
  • f⁻¹ тотальна: из сюръективности f. ∀y∈B ∃x∈A: f(x)=y → (y,x)∈f⁻¹.
  • f⁻¹ инъективна: из определения функции f. Если f(y₁,x)∈f и (y₂,x)∈f⁻¹, то (x,y₁),(x,y₂)∈f → y₁=y₂.
  • f⁻¹ сюръективна: из тотальности f. ∀x∈A ∃y∈B: (x,y)∈f → (y,x)∈f⁻¹. □
#21–22 Определение

Композиция. Образ и полный прообраз

Композиция g∘f: (x,z)∈g∘f ⟺ ∃y∈B: (x,y)∈f и (y,z)∈g Образ: f[X] = {b∈B | ∃x∈X: b=f(x)} Полный прообраз: f⁻¹[Y] = {a∈A | f(a)∈Y}
Ассоциативность композиции: (f∘g)∘h = f∘(g∘h)
Лемма о сохранении классов функций при композиции: если f и g тотальны (инъективны / сюръективны / биективны), то g∘f тоже тотальна (инъективна / сюръективна / биективна).
#23 Утверждение 5.7

Мощность полного прообраза через мощности прообразов элементов

Если f:A→B тотальна, то |f⁻¹[Y]| = Σb∈Y |f⁻¹[{b}]|

Следует из того, что прообразы разных точек не пересекаются, и правила суммы.

#25–26 Принцип Дирихле

Принцип Дирихле. Конечное множество. Мощность

Принцип Дирихле (принцип кроликов): Если k > n кроликов рассажены по n клеткам, то хотя бы в одной клетке сидит хотя бы два кролика.
Доказательство принципа Дирихле

Предположим противное: r₁,…,rₙ ≤ 1 для всех i. Тогда r₁+…+rₙ ≤ n. Но по условию r₁+…+rₙ = k > n. Противоречие. □

Конечное множество A: существует биекция f:[n]→A для некоторого n∈ℕ. Число n называется мощностью |A|.

Корректность определения мощности: если f:[n]→A и g:[m]→A — биекции, то n=m

Предположим n>m. Тогда g⁻¹∘f:[n]→[m] — биекция. По принципу Дирихле (n>m кроликов по m клеткам) найдутся i≠j: g⁻¹∘f(i)=g⁻¹∘f(j). Противоречие с инъективностью. □

#27–28 Лемма 5.13, 5.14

Сравнение конечных множеств. Лемма о тотальной функции из множества в себя

Лемма 5.13: Для тотальных функций на конечных множествах:
• f:A→B инъекция ⟹ |A| ≤ |B|
• f:A→B сюръекция ⟹ |A| ≥ |B|
• f:A→B биекция ⟹ |A| = |B|
Лемма 5.14: Если A — конечное множество, f:A→A тотальная:
• f инъекция ⟹ f сюръекция
• f сюръекция ⟹ f инъекция
(Для проверки биекции достаточно одного из двух!)

#30–31 Определения

Размещения. Перестановки

Размещение из n по k — слово длины k из n символов без повторений. Число размещений Ank.

Ank = n(n−1)(n−2)···(n−k+1) = n!/(n−k)!

Перестановка n-элементного множества — биекция f:A→A. Число перестановок Pn.

Pn = n! (частный случай Ann = n!/0! = n!)
#32 Определение

Сочетания

Сочетание из n по k — k-элементное подмножество n-элементного множества. Число Cnk.

Cnk = n! / (k!(n-k)!)
Доказательство формулы для сочетаний

Строим функцию f: размещения → сочетания: (x₁,...,xₖ)↦{x₁,...,xₖ}. Она сюръективна. Прообраз каждого сочетания S: количество способов упорядочить k элементов = k!. По утверждению 5.7: Ank = Cnk·k!. Отсюда Cnk = Ank/k! = n!/(k!(n-k)!). □

Индикаторная функция. Подмножества и индикаторные функции

χ_S(x) = 1 если x∈S, иначе 0
Биекция: S ↦ χ_S устанавливает взаимно-однозначное соответствие между подмножествами X и функциями X→{0,1}. Число подмножеств n-элементного множества = 2n.
Тождество C₀ₙ + C¹ₙ + ... + Cⁿₙ = 2ⁿ (комбинаторное доказательство)

Подмножества n-элементного множества делятся на: пустые (C₀ₙ), одноэлементные (C¹ₙ), ..., n-элементные (Cⁿₙ). По правилу суммы: сумма = 2ⁿ.

Аналитическое доказательство: Подставим x=y=1 в бином Ньютона: (1+1)ⁿ = Σ Ckₙ = 2ⁿ. □

#34 Бином Ньютона

Биномиальная формула. Биномиальные коэффициенты = числа сочетаний

(x+y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xkyn-k, где C(n,k) = Cnk
Теорема: C(n,k) = Cⁿₖ

При раскрытии (x+y)ⁿ получаем 2ⁿ слагаемых (слова длины n из {x,y}). После приведения подобных: коэффициент при xᵏyⁿ⁻ᵏ = количество слов с k буквами x = Cnk. □

#35 Треугольник Паскаля

Свойства треугольника Паскаля. Монотонные пути

C(n,k) = C(n-1,k-1) + C(n-1,k) — каждое число (кроме крайних единиц) = сумма двух чисел выше.

Монотонные пути в квадранте: Число путей из (0,0) в (a,b) при ходах (+1,0) и (0,+1):

T(a,b) = C(a+b, a) = (a+b)!/(a!·b!)
Связь с треугольником Паскаля

Построим биекцию: слово длины a+b с a буквами x и b буквами y ↔ путь (x=+1 по горизонтали, y=+1 по вертикали). Количество таких слов = C(a+b,a). Числа T(a,b) совпадают со строками треугольника Паскаля (повёрнутого на 135°).

Симметрия строк Паскаля: C(n,k) = C(n,n-k) — из формулы (перестановка k! и (n-k)!) или биекция «подмножество ↔ дополнение».

Возрастание в первой половине строки: C(n,k) > C(n,k-1) ⟺ 2k < n+1.

#37 Определение

Мультиномиальные коэффициенты

C(n; a₁,a₂,...,aₖ) = n! / (a₁!a₂!···aₖ!), где a₁+a₂+...+aₖ = n

Это число слов длины n, в которых a₁ букв x₁, a₂ букв x₂, ..., aₖ букв xₖ.

Два доказательства формулы

1. Комбинаторное: n! слов с различными буквами. Каждое слово посчитано a₁!·a₂!···aₖ! раз (перестановки одинаковых букв). Итого: n!/(a₁!···aₖ!).

2. Алгебраическое: Выбираем места для x₁: C(n,a₁) способов. Для x₂: C(n-a₁,a₂) способов. И т.д. Произведение всех биномиальных коэффициентов после сокращения даёт n!/(a₁!···aₖ!). □

#38–39 Определения

Сочетания с повторениями

Через разложение: Число слагаемых в (x₁+...+xₙ)ᵏ = число мономов степени k = число решений a₁+...+aₙ=k в натуральных числах.

Через мультимножества: Мультимножество с элементами из n-элементного множества размера k — каждый элемент входит с некоторой кратностью, сумма кратностей = k.

Число сочетаний с повторениями = ((n,k)) = C(n+k-1, k)
Доказательство формулы (монеты и перегородки)

#51–52 Определение

Транзитивное замыкание R*

R* — наименьшее транзитивное отношение, содержащее R. Три условия: R⊆R*, R* транзитивно, ∀ транзитивного T⊇R: R*⊆T.

Свойства (утв. 10.3):

  • Если R транзитивно, то R* = R
  • R** = R*
Теорема 10.7: R* = R ∪ R² ∪ R³ ∪ ...

Обозначим T = R∪R²∪.... Доказываем T = R*:

  1. T транзитивно: Если (x,y)∈Rᵏ и (y,z)∈Rˢ, то (x,z)∈Rᵏ⁺ˢ⊆T. ✓
  2. R⊆T: очевидно, T = R¹∪R²∪... ⊇ R. ✓
  3. R*⊆T: поскольку T транзитивно и R⊆T, из определения R* следует R*⊆T.
  4. T⊆R*: доказываем индукцией, что Rⁿ⊆R* для всех n. База: R¹=R⊆R*. Шаг: если (x,z)∈Rⁿ⁺¹=R∘Rⁿ, то ∃y: (x,y)∈Rⁿ⊆R* и (y,z)∈R⊆R*. По транзитивности R*: (x,z)∈R*. □

Отношение эквивалентности. Классы эквивалентности

Отношение эквивалентности — рефлексивное, симметричное и транзитивное отношение.

Примеры: равенство (idₐ), отношение «иметь тех же родителей», совпадение остатков от деления на n.

Теорема 10.15: R эквивалентность ⟹ делит A на классы эквивалентности

Определим C(x) = {y : xRy}. Проверим три условия:

  1. A = ∪C(x): Из рефлексивности x∈C(x). ✓
  2. C(x)∩C(y)=∅ или C(x)=C(y): Пусть z∈C(x)∩C(y), т.е. xRz и yRz. По симметричности zRy, по транзитивности xRy. Тогда для любого t∈C(y): yRt ⟹ xRt (транзитивность), т.е. t∈C(x), значит C(y)⊆C(x). Аналогично C(x)⊆C(y).
  3. C(x)=C(y) ⟺ xRy: Из xRy: x,y∈C(x), то есть C(y)=C(x). Обратно: если C(x)=C(z), то y∈C(z) и zRy, xRz (по симметричности), значит xRy. □

Построение отношения эквивалентности по разбиению: A = ∪Aᵢ (дизъюнктное) → (x,y)∈R ⟺ ∃i: x,y∈Aᵢ. Это отношение эквивалентности (проверка рефлексивности, симметричности, транзитивности очевидна).

#70–72 Теоремы

Висячие вершины. Остовное дерево. Корневые деревья

Изолированная вершина: d(v)=0. Висячая вершина: d(v)=1.

Теорема 12.8: В дереве с ≥2 вершинами есть не менее двух висячих вершин.
Доказательство (через следствие 12.5)

В дереве n≥2 вершин, n-1 рёбер. Пусть d₁,...,dₙ — степени. Изолированных нет (каждая — отдельная компонента связности, а дерево связно). По теореме о сумме: Σdᵢ = 2(n-1). Значит Σ(dᵢ-2) = -2. Каждое слагаемое ≥-1 (так как dᵢ≥1). Чтобы сумма была -2, хотя бы два слагаемых равны -1, т.е. хотя бы две висячие вершины. □

Теорема 12.9 (об остовном дереве): В любом связном графе есть остовное дерево. Строим: удаляем нe-мосты пока они есть, пока не останется дерево.

Корневое дерево: дерево с выделенной вершиной-корнем. Слои: слой 0 — корень, слой i+1 — вершины, не входящие в слои 0...i, но смежные со слоем i. Листья — висячие вершины, отличные от корня.

Монотонное остовное дерево: Для любого ребра {u,v} одна вершина лежит выше другой. Теорема 13.1: в каждом связном графе существует.

Эйлеров цикл. Критерий эйлеровости

Диаграмма Хассе H<: граф с рёбрами = непосредственно предшествующие пары.
Теорема 13.13: H< ациклический.
Лемма 13.14: Любой конечный порядок определяется своей диаграммой Хассе (a<b ⟺ b достижима из a в H<).
#77–79 Определения

Элементы порядка. Изоморфизм порядков. Операции с порядками

Наименьший элемент a: a≤x для всех x. Наибольший: x≤a для всех x.

Минимальный элемент a: нет x<a. Максимальный: нет x>a.

Отрезок [x,y] = {z: x≤z≤y}. Предельный элемент: нет непосредственного предшественника.

Изоморфизм порядков: P≅Q, если существует биекция ϕ:P→Q, сохраняющая порядок: x<y ⟺ ϕ(x)<ϕ(y).

Утв. 14.4: При изоморфизме сохраняются: наименьший/наибольший, минимальный/максимальный, отрезки (с их мощностью), предельные элементы.

Теорема 14.5: Все линейные порядки на конечных множествах одинакового размера изоморфны. (Доказательство индукцией: наименьшие элементы соответствуют друг другу, оставшиеся — по ИП.)
Покоординатный порядок P×Q: (p₁,q₁)≤(p₂,q₂) ⟺ p₁≤p₂ и q₁≤q₂ (линейность может не сохраняться!) Лексикографический порядок P×Q: (p₁,q₁)≺(p₂,q₂) ⟺ p₁<p₂, или p₁=p₂ и q₁<q₂ (Лемма 14.8: линейность СОХРАНЯЕТСЯ) Сумма порядков P+Q: все элементы P меньше всех элементов Q (линейность сохраняется)

Лексикографическое произведение и сумма некоммутативны.

#80 Теорема 14.12

Три определения фундированного порядка

Теорема 14.12: Следующие свойства равносильны:
(1) Любая убывающая цепь конечна (нет бесконечно убывающей a₁>a₂>...)
(2) Каждое непустое подмножество имеет минимальный элемент
(3) Принцип трансфинитной индукции: если ∀x∈P: (∀y<x: A(y))→A(x), то A(x) верно для всех x.

Примеры фундированных: ℕ, любой конечный порядок. Нефундированный: Z (бесконечно убывающая цепь 0>-1>-2>...).

Клики, независимые множества, теорема Рамсея
▼
#82–83 Определения

Клика. Независимое множество. Числа Рамсея

Клика — множество вершин, каждая пара соединена ребром. ω(G) — кликовое число.

Независимое множество — множество вершин, никакая пара не соединена. α(G) — число независимости.

ω(G) = α(Ḡ) (при переходе к дополнению клики ↔ независимые множества).

Теорема Рамсея: Для любых k,n существует N₀ такое, что в любом графе на N≥N₀ вершинах есть клика размера k или независимое множество размера n. R(k,n) — минимальное такое N₀.
#83–84 Оценки

Верхняя и нижняя оценки на числа Рамсея

Теорема 17.4 (верхняя оценка): R(k,n) ≤ C(k+n-2, k-1)

Из рекуррентности R(k,n) ≤ R(k-1,n)+R(k,n-1) и формулы C(n,k)=C(n-1,k-1)+C(n-1,k) по индукции.

Доказательство рекуррентности R(k,n) ≤ R(k-1,n)+R(k,n-1)

В графе на N₀=R(k-1,n)+R(k,n-1) вершинах выберем произвольную вершину v. N₁ соседей и N₂ несоседей. Если N₁≥R(k-1,n) — в подграфе соседей есть клика размера k-1 или независимое k → в исходном клика k (добавляем v) или нез. k. Если N₂≥R(k,n-1) — аналогично. □

Теорема 17.5 (нижняя оценка): R(k,k) > ⌊2^((k-1)/2)⌋ при k≥3

Вероятностное доказательство: случайный граф на n вершинах с вероятностью. Оцениваем вероятность наличия клики/нез. множества размера k. При n=⌊2^((k-1)/2)⌋ эта вероятность <1, значит существует граф без них.

Раскраски вершин графа. Двудольные графы
▼
#85–87 Определения

Правильная раскраска. Хроматическое число. Двудольный граф

Правильная раскраска в k цветов: c:V→{1,...,k}, такая что если {x,y}∈E, то c(x)≠c(y).

χ(G) — хроматическое число (минимальное k).

Критерий 1-раскрашиваемости: G не имеет рёбер ⟺ χ(G)=1.
Теорема 18.1 (критерий 2-раскрашиваемости): G двухраскрашиваем ⟺ все циклы в G имеют чётную длину.
Доказательство Теоремы 18.1

→: При 2-раскраске цвета вдоль пути чередуются. Цикл нечётной длины вернулся бы в ту же вершину с другим цветом — противоречие.

←: Фиксируем v₀, красим вершину x в 0 если parity(длины пути из v₀ в x) чётна, в 1 если нечётна. Это корректно (чётность длин одинакова по условию). Смежные вершины разного цвета: ребро {x,y} даёт путь длины odd(path)+1. □

Булев куб: Красим в 0 вершины с чётным числом единиц, в 1 — с нечётным. Соседи отличаются в одной позиции → чётности числа единиц различаются. ✓

Двудольный граф (L,R,E): V=L∪R, L∩R=∅, все рёбра между L и R.

Двудольные графы = бинарные отношения на L,R = подмножества L×R.

Паросочетания. Теорема Холла. Вершинные покрытия. Теорема Кёнига
▼
#88–90 Определения

Паросочетание. Совершенное паросочетание. Регулярный граф

Паросочетание — подграф, у которого степени всех вершин равны 1. µ(G) — максимальный размер.

Совершенное паросочетание: каждая вершина входит в паросочетание.

Число совершенных паросочетаний в K₂ₙ: P₂ₙ = (2n-1)!! = (2n-1)·(2n-3)···3·1 (формула через мультиномиальный коэффициент: (2n)! = (2!)ⁿ·n!·P₂ₙ).

Теорема Холла: В двудольном графе G=(L,R,E) существует паросочетание размера |L| ⟺ для каждого S⊆L: |G(S)| ≥ |S| (условие Холла).
Доказательство теоремы Холла (индукция по |L|)

База: |L|=1. У единственной вершины есть сосед → включаем в паросочетание. ✓

Случай 1: Существует S⊊L, ∅≠S, |S|=|G(S)|. Делим на два подграфа G' (S, G(S)) и G'' (L\S, R\G(S)). Для G' условие Холла выполнено по построению. Для G'': для X⊆L\S |G''(X)| ≥ |X|, т.к. |G(S∪X)|=|G(S)|+|G''(X)| ≥ |S∪X|=|S|+|X|. По ИП для каждого из них есть паросочетание нужного размера. Объединяем.

Случай 2: Для любого ∅≠S⊊L: |G(S)| > |S|. Берём произвольное a∈L, соседа b∈R. Для подграфа G'=(L\{a}, R\{b}) условие Холла выполнено: |G'(X)| ≥ |G(X)|-1 ≥ |X|. По ИП есть паросочетание размера n-1. Добавляем ребро {a,b}. □

Регулярный граф: степени всех вершин одинаковы.

Лемма 18.6: В регулярном двудольном графе с d>0 есть совершенное паросочетание.

Доказательство: |L|=|R| (из |E|=d|L|=d|R|). Для S⊆L: d|S| рёбер, правых концов ≤d|G(S)| → |G(S)|≥|S|. ✓

Следствие 18.7: В d-регулярном двудольном графе рёбра разбиваются на d совершенных паросочетаний (индукция: выделяем одно, остаток — (d-1)-регулярный).
#91–92 Теоремы

Вершинное покрытие. Теорема Кёнига

Вершинное покрытие S: у каждого ребра хотя бы один конец в S. τ(G) — минимальный размер.

Лемма 18.10: S — вершинное покрытие ⟺ V\S — независимое множество.
Следствие: τ(G) = n − α(G)
Утв. 18.11: τ(G) ≥ µ(G) (каждое вершинное покрытие содержит по одному концу каждого ребра паросочетания).
Теорема Кёнига: Для двудольного G: τ(G) = µ(G).
Доказательство теоремы Кёнига

Уже доказано τ≥µ. Докажем τ≤µ применив теорему Холла.

Возьмём минимальное вершинное покрытие X∪Y, X⊆L, Y⊆R. Строим G'=(X,G(X)\Y) и G''=(Y,G(Y)\X).

Проверяем условие Холла для G': для S⊆X, (X\S)∪Y∪G'(S) — вершинное покрытие. По минимальности: |G'(S)| ≥ |S|.

Аналогично для G''. По теореме Холла: в G' есть паросочетание размера |X|, в G'' — размера |Y|. Они не пересекаются → суммарное паросочетание размера |X|+|Y| ≥ τ. □
